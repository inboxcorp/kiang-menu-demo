# Kiang Restaurant — LINE LIFF menu demo

Proof-of-concept: scan a table QR → add the LINE Official Account as a friend →
the menu opens with the table number already filled in.

- `index.html` — the LIFF menu app (set `CONFIG.liffId`, or pass `?liffId=...`)
- `qr.html` — printable per-table QR sheet

Demo only. No credentials in this repo.
